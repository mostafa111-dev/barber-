## 🌟 نظرة عامة على المشروع

**كربيجي** هو نظام متكامل ومصمم خصيصاً لتلبية احتياجات إدارة صالونات الحلاقة اليومية. يعتمد البرنامج على قاعدة بيانات محلية مرنة (Excel و JSON مشفّر)، مما يضمن استمرارية العمل حتى في حال انقطاع شبكة الإنترنت تماماً مع إمكانية أخذ نسخ احتياطية واسترجاعها بسهولة فائقة.

---

## ✨ المميزات والوحدات الرئيسية

### 1. 💳 نقطة البيع والكاشير (POS & Cashier)
* إصدار وتعديل فواتير الخدمات ومبيعات المنتجات.
* دعم طرق دفع متعددة (نقداً، فيزا/محافظ إلكترونية).
* تطبيق الخصومات والعروض الترويجية والضرائب مع طباعة فورية للفواتير.
* تحويل المواعيد المحجوزة مباشرة إلى جلسات كاشير بنقرة واحدة.

### 2. 📅 إدارة الحجوزات والمواعيد (Appointments)
* عرض جدول الحجوزات باليوم، الأسبوع، أو الشهر.
* قائمة انتظار منظمة لتفادي تداخل المواعيد بين الحلاقين.
* ربط الموعد بالعميل والخدمات المطلوبة بدقة.

### 3. 👥 إدارة العملاء ونقاط الولاء (Customers & CRM)
* حفظ سجل تفصيلي لكل عميل (أرقام التواصل، سجل الزيارات، إجمالي الإنفاق).
* نظام نقاط ولاء ذكي قابل للتخصيص لاكتساب النقاط واستبدالها بخصومات أو خدمات.

### 4. ✂️ شؤون الحلاقين والموظفين (Staff & Payroll)
* تسجيل بيانات الحلاقين والكراسي ونسب العمولات على كل خدمة.
* تسجيل الحضور والانصراف يدويًا أو عبر استيراد سجلات أجهزة البصمة (CSV).
* حساب تلقائي للرواتب والعمولات والسلف والخصومات مع طباعة مسيّر الرواتب.

### 5. 📦 إدارة المخزون والمستهلكات (Inventory & Consumables)
* تتبع المنتجات المعروضة للبيع مع حساب التكلفة وسعر البيع وهوامش الربح.
* تتبع مستهلكات الصالون (مثل الصبغات، الشامبو، أدوات الحلاقة) وخصمها التلقائي.

### 6. 📊 التقارير والتحليلات المالية (Reports & Accounting)
* تقارير الأرباح والخسائر، حركة النقدية، المبيعات اليومية والشهرية.
* فلترة وتصدير التقارير وجداول البيانات بضغطة زر.
* نظام نسخ احتياطي يدوي وتلقائي يومي لحماية البيانات.

### 7. 🔒 الحماية وإدارة الصلاحيات
* نظام مستخدمين متقدم (أدمن، مدير، كاشير) بصلاحيات مخصصة لكل شاشة.
* كلمات المرور والبيانات الحساسة مشفّرة بأمان محلياً.

### 8. 🎨 تجربة مستخدم عصرية
* دعم كامل للغتين: **العربية (RTL)** و **الإنجليزية (LTR)** بضغطة زر.
* دعم المظهرين: **الداكن (Dark Mode)** و **الفاتح (Light Mode)**.
* خط **Cairo** المدمج محلياً لأعلى جودة عرض دون الحاجة لخطوط النظام الخارجية.

## 📂 هيكلية المشروع (Project Architecture)

```plaintext
barber/
├── Application/                 # الواجهة الرسومية (Frontend UI)
│   ├── index.html               # الهيكل الأساسي للتطبيق
│   ├── app.js                   # المنطق البرمجي وإدارة الصفحات
│   ├── features.js              # الخصائص التفاعلية والعمليات
│   ├── styles.css               # التنسيقات العامة والتصميم
│   ├── theme.css                # أنماط المظهر الفاتح والداكن
│   ├── fonts/                   # خط Cairo العربي المدمج
│   └── xlsx.full.min.js         # محرك التعامل مع ملفات Excel محلياً
│
├── Desktop/                     # بيئة سطح المكتب (Electron)
│   ├── main.js                  # المعالج الرئيسي وإعداد النوافذ
│   └── preload.js               # واجهة الربط الآمنة بين النظام والواجهة
│
├── Database/                    # طبقة تخزين البيانات المحلية
│   ├── Database.xlsx            # جداول البيانات (الخدمات، المبيعات، العملاء...)
│   └── Accounts.json            # الحسابات وصلاحيات الوصول المشفّرة
│
├── Backups/                     # النسخ الاحتياطية للبيانات
├── Demo/                        # بيئة تجريبية سريعة ببيانات افتراضية
└── Guides/                      # الكتيبات ودليل الاستخدام
```

## 🚀 تشغيل الكود في بيئة التطوير (Development Setup)

إذا كنت مبرمجاً وترغب في تشغيل المشروع على جهازك:

1. **استنساخ المستودع (Clone):**
   ```bash
   git clone https://github.com/mostafa111-dev/barber-.git
   cd barber-
   ```

2. **تثبيت الحزم المطلوبة:**
   ```bash
   npm install
   ```

3. **تشغيل التطبيق:**
   ```bash
   npm start
   ```
