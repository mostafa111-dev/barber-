كربيجي — النقل والتثبيت

1) أغلق التطبيق على الجهاز القديم.
2) شغّل Create Transfer Package.cmd لإنتاج Portable\Karbigi-Desktop-Transfer.zip بالبيانات الحالية.
3) انقل ملف ZIP واحدًا إلى جهاز Windows 10/11 بنظام 64 بت.
4) فك الضغط وشغّل Install Karbigi.cmd؛ سيُنسخ التطبيق إلى مجلد المستخدم ويظهر اختصار سطح المكتب.
5) افتح كربيجي من الاختصار. لا يلزم Edge أو إنترنت أو Node.js.

Database.xlsx وAccounts.json ينتقلان مع الحزمة. كلمات المرور محفوظة كبصمات مشفّرة. عند إعادة التثبيت على نفس الجهاز، لا يستبدل المثبّت بيانات المحل الموجودة.
